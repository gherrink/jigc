# The commit map

[commit-map.txt](commit-map.txt) maps every commit of this repository's pre-publication history to its commit here, one `old new` pair of full shas per line (2,535 lines). The history was rewritten once, on 2026-09-28, before the repository went public: third-party and employer material was removed or anonymized in every commit, and every commit was rehashed in the process (the GPG signatures on the original commits could not survive the rewrite and were dropped) — [pre-public-audit.md](pre-public-audit.md) records the method and the verdict, [implementation/public-hygiene.md](../../../implementation/public-hygiene.md) the rules that keep it from being needed again. **One commit has no counterpart** and maps to forty zeros: the original commit that recorded the working audit, whose only file was withheld from publication along with it — the audit record here is its replacement. Every sha cited in this repository's files was translated through this map when the rewrite landed, so a citation resolves here; the map is for a sha met anywhere else — an old log, a CI run, a message. The original history is kept in a private archive and is not published.
