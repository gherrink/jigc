# M51 Settle · fork F2 — the robust case (independent advocate)

**Position: robust-now on all five parts (a)–(e), with the git-dir cell declared out by quote.**

## 1. The hole — measured, not argued

I drove the cheap probe on three synthetic repos (`mktemp -d`):

| posture | `symbolic-ref -q HEAD` | `rev-parse --verify -q HEAD` | `rev-parse -q --verify MERGE_HEAD` |
|---|---|---|---|
| detached | **rc=1** | 0 | 1 |
| unborn | rc=0 | **1** | 1 |
| merge in progress | rc=0 | 0 | **0** |

The cheap probe answers **one of the three implementable cells** and returns *false green* on the two the baseline drove as live damage: `milestone create` pinning git's empty tree into a **committed** record (unrecoverable but for `discard --force`), and `--carry-staged` concluding the user's merge under jigc's own subject at exit 0. Production hits at HEAD: `MERGE_HEAD|CHERRY_PICK|rebase-merge|BISECT_LOG` = **0**; `symbolic-ref|abbrev-ref` = **0** (the two matches are in `crates/cli/tests/file_state_history_gate.rs`).

And `design/finalize.md:31` **already promises** cell three verbatim — *"Git in a committable state. No in-progress merge/rebase/bisect."* That is the razor fully available: stated in a locked artifact, violated at HEAD, demonstrable by driving. So the cheap cut ships a wave claiming *"no repository posture reaches a door … without that door having adjudicated it"* while leaving a **declared** posture rule unimplemented — a false completeness claim on the record, the exact failure this wave exists to correct (H3).

Cheap also misses `jigc setup` **by construction** (`setup.rs:1709` commits through `git_output`, outside the seam), and `setup` is one of the two doors EC-2 names as losing bytes.

## 2. Narrate-and-proceed is the wrong consent shape here

`task finalize` on a detached HEAD **destroys the task working area in the same act** that lands the prose on a branchless commit; the authored bytes then exist nowhere reachable, and `jigc validate` afterwards prints a **phantom** out-of-band edit routed *"review the out-of-band edit"* (baseline §2). Narration is consent-shaped only where the user can still recover. This repo settled that mold twice: `DESTROYING_DOORS` refuse with `--force` as the single consent, and M48/M50 chose refusal over narration at `milestone provision`, `discard`, `uninstall`, `task discard`.

The *placement* precedent is shipped too: `task::nothing_staged` (`task.rs:4290`) is a pre-flight predicate beside the commit seam whose own doc-comment condemns what cheap re-creates — *"routes to a re-run that can only fail identically."* Today's non-hook failures do exactly that: `milestone create` / `migrate-corpus` / `task discard` under an in-progress merge all print *"Fix the hook's complaint"*.

## 3. The superset registry is minimal-correct, not creep

`COMMITTING_DOORS`' predicate is *hook-capable* commit (`invocation_log.rs:95-97`); it is **derived into** `ERROR_CODE_REGISTRY` and driven by `commit_rejected_axis.rs` under a rejecting hook. `setup` commits `--no-verify`, so its cell **cannot exist** and its rejection already carries an identity (`setup.install-commit`). Widening is refused by construction (B2). Meanwhile three consumers want one subject: F2's posture probe, F4/EC-26's staged-set guard, N20's frame vocabulary. Without a home each hand-enumerates — and every hand-listed set this repo has audited grew (M46's fifth `.jigc/` writer; M49's 6→9, 5→47, 1→8). The superset is a struct plus a `⇔` fence; it duplicates no `COMMITTING_DOORS` fence, it **contains** it (`COMMITTING_DOORS ⊆ …`, itself assertable).

Part (d) is the same discipline. `git_commit` receives a bare `&Path`, so a seam probe must guess `.jigc/worktrees/.combine-<pid>` by path shape — the class M50's audit condemned (`fanout_worktree_paths`' `path.is_dir()`: a claim about shape where the question is about bytes). A typed argument makes a new call site refuse to compile until it states its posture. The boundary's live act, `overlay_docs_commit_and_ff` (`task.rs:4407`), is one function both arms funnel through, called with the operator's `repo_root`: verified reuse, not new machinery.

## 4. The strongest cheap counters, answered

- **"A superset duplicates the fences."** It cannot — the registries answer different questions (*who can be hook-rejected* vs *who acts on the user's repo*). The superset carries no error identity, so it triggers no `ERROR_CODE_REGISTRY` derivation and no rejection cell.
- **"Refusing breaks CI runners that check out a sha."** Refusal binds committing/moving doors only. Read verbs — `validate`, `doc show`, `doc list`, `describe`, orientation — are in no registry and are untouched. This repo's own CI (`actions/checkout@v4`, which detaches) runs zero jigc doors. A CI that *does* run `task finalize` detached is today producing a commit that vanishes at the next checkout; refusal converts silent loss into one line (`git switch -c`).
- **"GIT_DIR users are legitimate."** Agreed — so the robust arm **declares that cell out with `repo.rs:9-16` quoted** ("so a fake `.git` can never walk up to, and bind against, a real ancestor repo"; ~15 fixtures depend on it) rather than omitting it silently. Env-scrubbing is invariant-adjacent (F1) and is a separate, stated decision.
- **"Bisect users."** Mid-`bisect` nobody is authoring docs, and `finalize.md:31` already says so; the route is `git bisect reset`, non-destructive, with the work still in `.jigc/tasks/` — which is what today's exit 0 deletes.

## 5. What the cheap cut costs

It is cheap only inside the wave. After the pin a stated consent flag is a **pinned** flag with pinned semantics: *narrate → refuse* is breaking, *refuse → add a consent flag* is additive. Cheap spends the one-way door in the wrong direction and leaves standing: exit-0 loss at `setup` and at the fan-out landing, a bricked committed milestone record, a merge concluded under jigc's subject, and a `finalize.md:31` promise that must then be **struck** rather than kept — a documented capability deleted on the eve of 1.0.

## 6. The robust scope (minimal-correct)

1. `RepoPosture` — three predicates, each the one-liner spiked above; the git-dir cell declared out with its quote.
2. One registry — *doors that commit or move on the user's behalf* — `⇔`-fenced against the clap leaf tree, with `COMMITTING_DOORS ⊆` asserted.
3. Probe **at the door before work** and at `overlay_docs_commit_and_ff`; one code + route per posture; `--force` the single consent, matching the destroying-door mold.
4. `DedicatedWorktree` as a typed argument at the seam.
5. One `finalize.md` Preflight paragraph (kept, not struck) plus the linked-worktree subject-repo sentence — which repo, which branch, on the ack.

Roughly one increment sharing F4's registry; the shared registry is why this is one increment rather than two half-swept ones.

**Verdict: robust-now** — the cheap probe is provably 1-of-3, false-greens both cells that lose bytes, misses `setup` structurally, converts a stated design rule into a deletion, and ships the consent shape in the one direction the 1.0 pin makes expensive to reverse.
