# focusflow

## Vision

A lightweight mobile app that turns vague good intentions into visible daily streaks, so solo users who abandon heavyweight planners actually stick with their habits.

## Requirements

### Log a habit in one tap  {#log-a-habit-in-one-tap}

A user can log a habit with a single tap from the home screen — no menus, no forms.

### Show the current streak  {#show-the-current-streak}

The current streak for each habit is shown front and center, large and unmissable.

### Daily reminder  {#daily-reminder}

A gentle daily reminder nudges the user at a time they choose.

### 30-day history heatmap  {#30-day-history-heatmap}

The user can review a 30-day history of completions as a simple calendar heatmap.

## Context

Built for individuals, not teams — no sharing, no managed accounts, no backend beyond anonymous sync. The bet is that radical simplicity keeps people coming back, so every feature must justify itself against the one-tap-logging core.
