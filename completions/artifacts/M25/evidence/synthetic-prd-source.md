# Product Brief: FocusFlow

## Overview / Vision

FocusFlow is a lightweight mobile app that turns vague good intentions into visible daily
streaks, so solo users who abandon heavyweight planners actually stick with their habits.

## What it must do

We need the following before launch:

- A user can log a habit with a single tap from the home screen — no menus, no forms.
- The current streak for each habit is shown front and center, large and unmissable.
- A gentle daily reminder nudges the user at a time they choose.
- The user can review a 30-day history of completions as a simple calendar heatmap.

## Constraints & background

Built for individuals, not teams — there is no sharing, no accounts to manage, no backend
beyond anonymous sync. The bet is that radical simplicity is what keeps people coming back,
so every feature must justify itself against the one-tap-logging core.
