## The hole the cheap cut leaves

The wave's declared surface is *"every surface 1.0.0 pins says what the binary does"* (M51's claim,
which M52 inherits). Fork 6 is the last chance to make that true of the **machine** surface — the one
the vision names as jigc's reason to exist (*findings as data, the stable `(code, target)` key*).
The cheap arm ships the pin over four surfaces that demonstrably lie, and the pre-pin rule at
`command-output-contract.md:486` says a key blessed by omission is blessed for the life of `1.x`.

### Spike 1 — DEFECT 1, driven at `task finalize`, not only `milestone finalize`

`dev/jigc-rig fresh`; task filled to green; `.jigc/version` downgraded so the stamp refresh writes it;
pre-commit hook appends to `.jigc/version` and exits 1:

```
$ jigc task finalize harden-the-read-cache --format json  → exit 1, stdout 0 bytes
$ python3 -c "import json; json.load(open('err.txt'))"
  JSONDecodeError: Extra data: line 4 column 1 (char 380)
  raw_decode → keys ['error'] ; 459 bytes dropped after the document
  "rollback-conflict" in the parsed object: False
```
The dropped 459 bytes are the **only** place the parked pre-image is named:
`.jigc/displaced/version.pre-image.1789597994076978000`. Driven: `jigc validate --format json` → 0
hits, `jigc task validate … --format json` → 0 hits. So a driver following the contract's own
predicate (*parse stdout; if empty, parse stderr*) **crashes**; a tolerant driver silently loses the
blocking finding **and the path to the user's raced bytes**. This is not a cosmetic stream defect —
it is the one cell where jigc parks a human's bytes and tells nobody who can read it.

## The two stock rationalizations, refuted

**"No live case."** Refuted by spike 1: I drove the rollback conflict through the ordinary
`task finalize` door on the release binary in four commands, with a hook — the most ordinary third
party in the repo. DEFECT D's *"a deleted cwd is exotic"* bound is already overtaken by LD-1, whose
trigger is a **one-character typo in `.jigc/config/packs.yaml`**, a file the operator is invited to
hand-edit.

**"Premature generality / this is new capability."** It is not. `envelope_finding_error` **ships**
(`render.rs:4870`), its doc-comment already states the governing rule — *"a code the contract lists
under a declared target form is one it promises a driver can key on, so that code's doors owe the
envelope"* — and `ENVELOPE_ARMS` is the declared home. Measured: **22 flattened `finding_error`
production sites across 12 files vs 6 envelope sites**; switching one is a **one-token edit**. The
wave's boundary (*fixes + understandability, no new capability*) is satisfied: nothing here mints a
verb, a flag or a workflow.

**"Is it a 21-door sweep?" — no, and the question is mis-posed.** The 21 `{error}` rows in the `bare`
cell and the 45 outside a repo are `locate::not_set_up()` / `not_in_repo()` — bare `anyhow!` with **no
finding behind them** (read: `locate.rs:53`, `:95`). `{error}` is the *correct* arm for those. The
doors with a finding behind a flattened `{error}` are exactly the 22 `finding_error` sites, and DEFECT
1 is **one producer** (`carry_rollback_conflicts`, `task.rs:4328`) plus its sibling (`config.rs`'s
relocation prose). The reshape is one arm declaration + two producers, not a sweep.

**`SCHEMA_VERSION` 3→4 — who reads it?** Measured: **nothing checks it.** `grep` for a version
mismatch across `crates/engine/src` and `crates/cli/src` returns only the slug-rule manifest check.
The readers are the shipped `doc-code` probe's mirrored const (`probes/doc-code/src/main.rs:58`), 5
golden files and ~6 test assertions. No third-party probe exists (the pack platform is a declared
non-goal). And adding `findings` beside `error` is **additive**, which the pre-pin rule permits with
**no bump at all** — the charter's `doc schema contract-version` premise was already corrected to
`SCHEMA_VERSION` by the baseline; the honest answer is that even that is not owed.

## The cheap arm's price, per item

- **DEFECT 1 cheap ("suppress the finding under json, write the gap down").** Costs a *documented*
  data-visibility hole: the only naming of a parked human file lives on a surface the machine cannot
  read, and the gap is frozen until 2.0. It also converts a law-1 lie into a **declared** one, which is
  strictly worse than today — today it is a bug; declared, it is a promise.
- **DEFECT A cheap = robust** if the target is `{findings, schema_version}`. The cheap arm as posed is
  right *only* because it names that arm. If the Settle drifts to `{error}`, it is a regression.
- **DEFECT D cheap ("silence pack.rs under json").** Silences the *authoring fault* `pack.rs`'s own
  comment says must be surfaced, leaves the 24-site class open, and leaves
  `refuse_on_posture`'s `current_dir().ok()?` silently skipping the whole M51 posture family — a hole
  M52's own fork 2 claims to close.
- **LD-2 cheap ("declare it on the `doc schema` side").** `milestone-record.yaml:62` says
  `{ id: base, type: string }` — the schema is **true**; the projection is the special case. So the
  cheap arm blesses a cross-surface type contradiction on the one surface whose purpose is machine
  type-checking, for the life of 1.x. The honest fix is a projection marker on `doc schema`, and
  **fork 5 needs a 6→7 bump anyway** (G-23's `placement`/`singleton` key) — so this rides an already-
  paid one-way door for ~nothing. Declining it pays the full price and gets no discount.
