## 2. The keys, as the run's ledger will take them

*Usable alone.* Every live key of [the findings](byte-table-findings.md), **sixty-five**, one line each, grouped by the door that does it and then by what it does. A line reads:

`key` — **doors** · **red here / on rc.24** (cells; *+n on demand* where cells off the gate carry it) · **class** · **reg.** · **wrong** · **ruling** · **fix pass**

- **red here / on rc.24**: the key's cells red on this tree's debug build and on the previous release's rebuild (print); `no cell` for a key no cell can see — a key of words, or a doc's.
- **class**: the classification the expected-red list holds the cells to (`EXPECTED_RED`): *lost*, *git moved* (git's state moved outside its allowance), *outside* (written outside its allowance), *refusal changed* (refused, and changed what a refusal may not), *not listed* (not the listed outcome).
- **reg.**: *yes* where a cell is red here and clean on the previous release; *no* otherwise. One key has one.
- **wrong**: which of the design doc and the product changes — *code*, *doc*, or both.
- **ruling**: the rows' record's §6 entry it was decided under, with its date; *bound 1* and *bound 2* are the human's declared bounds of 2026-10-06, the second retired on 2026-10-19; *R1* the human's ruling of 2026-10-20 on acting sweeps; *—* none.
- **fix pass**: the row of [the fix pass's ledger](../../fix-pass-rc25/findings-ledger.md) it repeats or sits beside, as the findings cite it; *—* none cited.

## 9. How each count is read off — the commands

Each runs from this directory over the committed files; *red* is every classification but *holds* and *refuses, nothing changed*, and a *not run* is counted apart.

```zsh
c=byte-table-record-cells.tsv; n=byte-table-record-needs-and-excused.tsv; p=byte-table-record-pairs.tsv; d=byte-table-on-demand-cells.tsv
clean='^(holds|refuses, nothing changed)'
awk 'NR>1' $c | wc -l                                                               # 760 cells
awk -F'\t' -v r="$clean" 'NR>1 && $10 !~ r' $c | wc -l                              # 175 red on this tree
awk -F'\t' 'NR==FNR{if($0!~/^#/)od[$1]=1; next} FNR>1 && !($1 in od)' $d $c | wc -l # 580 in the gate
awk -F'\t' -v r="$clean" 'NR==FNR{if($0!~/^#/)od[$1]=1; next} FNR>1 && !($1 in od) && $10 !~ r' $d $c | wc -l   # 161 red in the gate
awk '!/^#/' $d | awk 'NR>1' | wc -l                                              # 180 on demand
awk -F'\t' 'NR>1 && $7 !~ /^(holds|refuses, nothing changed|not run)/' $c | wc -l  # 269 red on the previous release
awk -F'\t' 'NR>1 && $7 ~ /^not run/' $c | wc -l                                     # 2 not run there
awk -F'\t' -v r="$clean" 'NR>1 && $10 !~ r && $7 ~ r {print $1}' $c                 # the one regression
awk -F'\t' 'NR>1 && $10 ~ /^lost/ && $7 !~ /^lost/ {print $1}' $c                   # lost here and not there: 2
awk -F'\t' 'NR>1 && $6 != "-" {print $6}' $c | sort -u | wc -l                      # 43 keys with cells
awk -F'\t' 'NR>1 && $5 != "-" {print $5}' $c | sort | uniq -c                       # 1 bound 1
sed -n '/^== needs ==/,$p' $n | awk -F'\t' 'NR>2' | wc -l                           # 680 needs
sed -n '/^== needs ==/,$p' $n | awk -F'\t' 'NR>2 && $3 ~ /^scheduled/' | wc -l      # 11 scheduled
sed -n '1,/^$/p' $n | awk -F'\t' 'NR>2 && NF==4' | wc -l                            # 298 lines
sed -n '1,/^$/p' $n | awk -F'\t' 'NR>2 && NF==4 && $3==0 && $4==0' | wc -l          # 179 excusing nothing
awk -F'\t' -v r="$clean" 'NR>1 && $1 !~ r && $2 !~ r {s+=$3} END{print s}' $p       # 174 red on both
```
