# Before the first stabilization run opens

## Reuse Exercised

Read, not run, at planning — each reuse is exercised by its task's red-first arms before anything is built on it.

- The record script's writers for the regression base's round-2 fixtures: not exercised; listed as not established, and the builder halts if the state refuses them.
- `Link::at` as the product's public answer for a link's way out: read at its signature. The act check's second commit exercises it — another target for the planted link changes what it computes, and the case turns red.
- The harness's probe path for a fourth probe: read — `probeFault` admits only `probe`, `scratch` and `seconds`; `agentR` retries twice unless called `once`; `gitStep` passes no `once`. The build adds a probe-only path, and a fence arm holds the launch count.
- The write guard: read — it binds only inside an opened run. The probe task extends it, red first over three agent types.
- Cold start: the review registry starts without the byte table's review ranges and is backfilled in one listed commit; a review whose range cannot be shown stays uncovered, so its commits are reviewed again.

## Cheap Vs Robust

Every fork was taken on the robust side, or deferred with a trigger.

- Known findings fixed before the opening, or by the run: the human ruled the run. Only tools a pre-opening task or an instrument needs are built; every other candidate moves to the tool candidates list with its trigger, so nothing is dropped silently.
- Review only what moved, or everything the test stage consists of since its last review: the human ruled everything, with "reviewed" decided by commit range, not by name.
- A route's acts and operands checked, or left alone: the human ruled them checked, and a route that leaves one to be inferred is a finding class of its own.
- The returned-text probe built and run now, or declared a bound: the human ruled it built and run, as a scoped exception.
- Engineering forks, each taken robust: one serial catalog lane (not two sub-lanes); new reasons batched at the end of each batch, with an unruled reason refused at the close (not a halt per task); the frame reviews early (not all at the end, which would put 22–63 hours on the critical path and could invalidate tests built on a faulty frame).

## Census

Each new rule, how its members were found, and where it is enforced.

- Every refusal site answered: 125 fixed sites, 73 codes the dynamic sites declare, and an estimated 20–60 codes of uncatalogued prefixes. Found by the catalog's own source scan, which is a finder. The fence holds it, and at the close the catalog refuses an unscheduled site, an owed code, an unruled reason and a not-built case; a closure arm then holds that every code-shaped prefix in production source is catalogued, which catches what the scan's pattern would miss.
- The act check: every case, over all 27 kinds of act. Enforced by an exhaustive match, so a new kind does not compile until it has an entry, and by the classification arm.
- Coverage by commit range: every file of the range lands in exactly one of four classes. The lister would miss a merge that resolved a conflict, so such a merge counts as uncovered unless a review read it.
- The guard while a probe runs: every subagent type of the session, held by red arms over three types. Whether the hook sees every subagent's calls is not established, and the builder halts if it does not.
- The 80 % rule for CI: every leg, read after each push.
- The routes that ask to put the file itself back: three print sites, found by grep and confirmed by a reviewer.

## Design Complete

Every net-new piece has settled behaviour and a red-first acceptance in its task:

- the probe — its agent set, `once`, the guard's allowlist under the marker, a planted text that is harmless if obeyed, three verdicts, and at most one re-invocation under a fresh root;

What is not settled is listed as not established, each with what settles it: where the guard reads that a probe is active (the builder halts if it cannot), the dynamic sites' code counts, the round-2 fixtures, refusing golden updates under CI, whether an act needs more than one verb, whether every review range can be recovered, and how fast CI's legs grow.
