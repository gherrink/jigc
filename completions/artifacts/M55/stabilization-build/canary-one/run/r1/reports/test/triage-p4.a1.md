## How the grades were given

The closing condition is read as its entry words it. `no-lost-files`: in a healthy repository used as documented, no jigc command at exit 0 destroys bytes no git object holds or commits content the user did not ask for; planted states are bounds only once declared with their reach. `working-product`: no command that works on the previous release in a supported layout stops working, and every refusal's route works as printed. No item of this pass touches `usable-by-agents` or `migration-works` by their instruments.

- **`breaks`** — the report says a refusal's printed route was run as printed and failed, in a state nothing was planted to reach (three rows), or names a route that as printed points at the wrong path (one row).
- **`unclear`** — every cell its reporter says nobody drove; every route its reporter printed and did not run; every candidate-only difference nobody looked into; every route that failed where the state is unusual enough that the clause's scope is in doubt; every route with one dead alternative beside a working one (three verifiers of pass 3 judged that shape by a reading they say is not theirs to fix).
- **`no-break`** — a sentence, a path spelling, a count or a missing name on a surface that refuses nothing or prints no route, identical on both binaries where the report says so; a pinning, coverage or process note that reports no behaviour; a design question no clause speaks to. It is still a row.
- **`needs-bound`** — two kinds, both the human's: a loss or a hang whose only exclusion from a clause is that the state was planted, where the run declares no bound (eight rows); and a question about how far a clause's words reach, which its reporter hands to the human in so many words (five rows: D4, O4, V8, Y1, AJ10).
- A reporter's severity was not used. No finding was held back, ranked or proposed a fix.

**Rows graded `no-break` that depend on a reading the human has not given.** If the reading in row D4 (a refusal that prints no route breaks the second clause) is adopted, these re-grade: B3, B5, C4, C5, C8, C9, O5, X4, AA1, AJ1. If the reading in row O4 (a false green or a false count at exit 0 that the previous release prints too) is adopted: C3, N3, AJ5, and O4's own parent rows.
