Derive the axis before you touch code. An audit finds a defect by hitting it —
one repro, one site — so the sites it reports are a lead, not the scope: name the
class the defect belongs to (the registry it enumerates, the call set it ranges
over, the file family the rule binds), then report that class's full membership,
converting every member or saying why one is out. A fixer handed a list fixes the
list, and the class ships half-closed.

The red test is the finding reproduced. Drive it until it fails for the defect
itself, not for an incidental compile error standing in for it, and make it
iterate the axis you derived rather than pin the one site the audit named — a
rule-shaped fix whose test pins its reported instance is itself a finding. Only
then the minimal green, and refactor only what this fix touches.

`git add` the paths this fix touched, inside THIS worktree — your own paths and
no others. A sibling fixer is closing its own finding in its own worktree at the
same time, and a sweep of the tree would carry its in-flight edit into your
change.

Never `git commit` and never `jigc task finalize` here. The milestone's finalize
is the only commit boundary of a fix round: either command lands a commit on this
worktree's detached HEAD and strands the fix outside that boundary.

Run your project's own test, lint, and build gate — the commands this project
already uses to prove a change is sound — and confirm every one passes before
you finalize. Use whatever the project's configured gate is; do not assume a
particular toolchain. A green gate is what separates a finished change from one
that merely compiles in your head.

finalize renders the commit doc; it does not fill it, so set its header and prose
first. Inside slot prose, the reserved heading depths are schema-relative to the
address you write — the CLI owns the section, item, and sub-label heading levels
there, so your headings sit below them; Setext headings are rejected at every
depth, and a rejected write names the shallowest depth free at that address.
